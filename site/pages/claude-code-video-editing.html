Why an editor, not a script

An agent can cut video with ffmpeg commands, but it can’t see the result, and you can’t easily fix what it did. In gmclip every feature is one command, and the app, the command line and the MCP server all call the same list. So the agent edits the real project: you watch each change appear in the timeline, undo any of it, and keep going by hand. The agent can also look at rendered frames of the cut, so it frames shots from what’s on screen rather than guessed coordinates.

What your agent can do

  • Read the transcript of every video in a project and find the moments worth posting, then sweep for the ones it missed
  • Grow a story from a moment: it suggests, you apply
  • Cut by striking words, tighten pauses and fillers, fix misheard words
  • Set 9:16 and 16:9 framing, crops and facecam layouts, then check the frames
  • Style captions, add a text hook, draft titles and per-platform copy
  • Run overnight batches with a budget limit
  • Pick up a comment from your phone review with “Fix with my agent”

Two ways to connect

Start a session inside gmclip

Open Agents, pick Claude Code, Codex, pi or opencode, and click New session. gmclip launches the agent on your own login with only gmclip’s tools, scoped to the project, video or cut you picked. Each run is isolated from your other agent settings.

Connect the agent you already run

On the same page, Connect one… adds gmclip as an MCP server to Claude Code or Codex through their own CLIs (claude mcp add, codex mcp add), and shows you the change before it writes it. Then ask in your terminal as usual, for example:

Open my latest stream in gmclip, find three moments that work as Shorts,
and make a 9:16 cut of each with captions. Don't export.

An agent can do anything you can in a project except change owner settings, which stay with you.

Compared with other agent video tools

video-use lets Claude Code edit video through scripts and sends audio to ElevenLabs for transcription. gmclip transcribes on your machine and gives the agent a full editor with undo, a timeline you can see, and the same project you open by hand. Opus Clip offers an MCP connector on its paid plans; gmclip’s is free.

Questions

Does gmclip charge for AI?

No. gmclip is free and open source. The agent runs on your own Claude, ChatGPT or other plan.

Which agents work?

Claude Code, Codex, pi and opencode from inside the app. Other MCP clients can use gmclip’s stdio server, gmclip mcp.

Can the agent publish or delete my videos?

It edits projects. Exports and overwriting source media happen only when you ask, and every edit can be undone.
