# Rubric: screen + face (v1)

Score each candidate moment 2–5 by whether it shows a result a viewer can see: something
built, fixed, measured or broken on screen, with the claim visible and not only spoken.

- **5**: a concrete result on screen with a number or a before/after (it ran in 67 s, the
  build went green, the bug is gone), and the person says what it means.
- **4**: a clear demo of one thing working, or a surprising failure, with the screen
  showing it.
- **3**: a useful explanation or opinion with the screen as backdrop only.
- **2**: setup, typing, waiting, reading docs aloud, or a claim the screen contradicts.

Span: open on the result when it can stand alone, otherwise on the sentence that sets it
up; end when the point is made. 20–75 seconds for 9:16; a 16:9 cut is a 3–15 minute
story of one task.

Types: `result`, `demo`, `fail`, `tip`, `opinion`, `story`.

Numbers come from the footage: never score up a number the screen does not show.
